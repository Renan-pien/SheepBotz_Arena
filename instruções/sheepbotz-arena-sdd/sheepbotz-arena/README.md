# SheepBotz Arena

**0 testes · 0% de cobertura**

> Linha gerada automaticamente a partir dos relatórios de testes e cobertura (constitution, Princípio V). Não editar à mão.

Simulador genérico de robôs móveis no navegador para a equipe **Univille SheepBotz**: lógica em 2D, visualização 3D e modalidade de demonstração **sumô**. O usuário descreve o mundo num arquivo JSON, escreve o controlador de cada robô em JavaScript e acompanha a luta com executar, pausar, avançar tick a tick e reiniciar.

Projeto desenvolvido com **Spec-Driven Development** (GitHub SpecKit).
